01 — Selected work

Things I’ve built and shipped.

Featured · 2026 · founder & sole developer

VoxelPort

A free, open-source app that lets anyone host a Minecraft server from a PC or an Android phone, with no port forwarding. I made it because Jio and Airtel make port forwarding impossible. It’s an Electron desktop app, a Go relay running in India, an Android beta, a React website and a Discord bot with AI-assisted support tickets. Built with an AI coding assistant, and fully open source.

  • Electron
  • Go
  • React
  • TypeScript
  • Android
  • WebSockets

03 — The journey

Student, builder, team lead.

Hi, I’m Garv. I like taking a project from a blank file to something live: apps, relays, link pages, real-time widgets, 3D backgrounds, small tools.
