VoxelPort — Minecraft Server Tunneling

Host a Fabric server — or an Open-to-LAN singleplayer world — over the internet with zero port forwarding. The mod opens an outbound encrypted WebSocket to VoxelPort's relay, which hands back a public address that vanilla players can join directly, no mod required on their end. Built the Fabric mod, the relay, the website, and a cross-platform Electron desktop app.

Java Fabric WebSockets React Electron

WaypointsLite — PaperMC Plugin

A lightweight Minecraft server plugin giving non-OP players teleport requests with a click-through accept/deny GUI, personal waypoints (/waypoint set|go|list|delete), and toggleable live server stats in the sidebar. Built for servers that don't want to hand out full essentials-style permissions just to let players teleport to each other.

XPMerger — PaperMC Plugin

A performance plugin that merges nearby XP orbs into bigger clumps to cut down on entity lag from wither farms and mob grinders. Runs two strategies together: an instant merge on ExperienceOrbSpawnEvent that catches burst drops before they ever tick, and a periodic sweep that buckets orbs into a spatial grid so it only compares nearby orbs instead of checking every orb against every other one.

Java PaperMC / Spigot API Maven
